# 後台全面原生化（2026-10-23）

全部後台使用 SvelteKit 3.1 / Svelte 5。React、React DOM、React Day Picker、Lucide React、Radix React 及其型別依賴已移除；`admin-compat/`、兩個掛載橋接元件與 JSX 設定已刪除。鎖定檔中沒有 React 或 Radix React 套件。歷史文件的 TSX 檔名僅為遷移來源說明。

## 功能範圍

- `admin/workspace/`：今日工作台、預約清單／日曆、代訂、既有客戶帶入、改期、可用時段、狀態確認、叫號、排班、休假、批次樣板及客戶清單。
- `admin/manage/`：登入、平台總覽、院所列表與分享、院所新增／編輯／Logo、完整營業時間與休息時段；人員完整檔案／照片／服務對應／休假；服務時長與價格、公告發布；客戶聯絡與照護註記、身分唯讀資訊及完整狀態時間軸；訪客與客戶分析、看診統計；訂閱編輯、續約、試用與密碼變更；員工／會員、院所綁定、角色、密碼重設、帳號刪除；加入申請審核及服務分類管理。
- `admin/policy.ts`：掛載前檢查角色與院所歸屬，未授權頁面不發送其管理請求。後端仍獨立驗證全部授權、訂閱資格與交易。

## 保留的契約與改善

共用原有 Svelte 登入、token、主題及 API 代理，不新增認證狀態或後端介面。身分識別欄位不能在客戶檔案修改，再次預約仍需核對完整身分證。所有寫入驗收只使用虛構 API 攔截，不修改正式資料。

表單失敗保留輸入並顯示後端原因；刪除、客戶停用、試用與審核有確認步驟。帳號註冊成功後若院所或角色設定失敗，保留新帳號識別碼接續設定，避免重複註冊。人員服務對應逐項記錄成功結果，失敗後可繼續重試。

營業設定保留休診日、最多兩段休息及未設定時依班表的規則。Logo 上傳不重設未儲存表單。訂閱續約保留原方案與付款歷史，月末夾限且以台灣時間計算到期日；免費方案仍可查訪客數，不請求未開通的付費分析。

## 驗收方式

`pnpm check`、`pnpm lint`、`pnpm build`、`pnpm test` 及 source-only Snyk Code 掃描。`tests/admin-native-complete.test.mjs` 覆蓋完整路由、桌面／手機、設定與管理寫入、角色與訂閱限制、失敗重試；同時檢查載入 JS 與原始碼／依賴，防止 React 再次進入網站。

部署驗收可設定 `ADMIN_COMPLETE_ORIGIN`；每日工作區可設定 `ADMIN_WORKSPACE_ORIGIN`。兩者皆攔截全部 API，正式網址只用於驗證實際 HTML、靜態資產與瀏覽器操作。公開 API 與代理另做唯讀部署驗收。

本機驗收：型別檢查 0 錯誤／0 警告、ESLint 與正式建置通過；323 項測試中 322 通過、1 項遠端環境檢查略過，0 失敗。完整原生後台新增 14 項測試；安全副本含 379 個 source-only 檔案；因 Snyk 不直接支援 `.svelte`，另以 Svelte 5.57.2 編譯 249 個元件並掃描其 JavaScript，未加入執行環境變數、憑證或資料。掃描結果與檔案雜湊記錄於發布驗收文件。

最終安全結果：Snyk Code 0 問題，實際分析 125 個 TypeScript、249 個 Svelte 編譯 JavaScript 及 1 個 HTML 檔。379 份來源副本雜湊與發布來源一致。

## 後台元件與載入畫面更新（2026-10-23）

院所及平台管理共用 shadcn-svelte 外框，表單、卡片、表格、頁籤與狀態標籤沿用專案元件。工作台精簡預設篩選，更多條件按需展開；手機採 Sheet 選單與常用功能列，長表單動作列固定在可操作範圍。

20 處後台載入狀態使用 shadcn Skeleton 組合占位，依資料呈現對應卡片、表格、表單、班表或時段形狀；載入失敗會結束骨架並提供錯誤與重試。使用者澄清 Skeleton 指 shadcn 占位元件，沒有採用 Skeleton UI 元件庫，也未變更 SvelteKit 3 架構。

更新驗收：326 項測試中 325 通過、1 項遠端檢查略過，0 失敗；型別檢查 0 錯誤／0 警告，lint 與正式建置通過。桌面 1440px、手機 390px 的後台畫面沒有瀏覽器錯誤或橫向溢出。新增 3 項載入／錯誤／手機測試。

經使用者明確授權，Snyk Code 分析 128 個 TypeScript、270 個 Svelte 編譯 JavaScript 及 1 個 HTML 檔，0 問題。403 份來源副本雜湊與發布來源一致；副本不含環境檔或憑證。
