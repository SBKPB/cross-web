# 後台 UI 與操作流程檢查（2026-10-23）

本次針對院所櫃台與平台管理兩種情境，以虛構資料檢查頁面、鍵盤、瀏覽器歷史、亮暗模式、手機短視窗及失敗重試。全站維持 SvelteKit 3.1／Svelte 5／shadcn-svelte。

## 判斷

先前介面具備完整功能，但選取狀態、手機換行與院所情境導覽仍會讓使用者停下來判斷。此次修正後，日常預約、客戶回訪、設定維護與平台管理都有明確入口、狀態與下一步。

| 問題 | 對操作的影響 | 本次調整 |
| --- | --- | --- |
| Tab 選取底色與背景過於接近 | 難以辨識目前分類或檢視 | 品牌色選取底、完整底板，底色立即切換 |
| 手機設定 Tab 換行但容器高度固定 | 公告項目擠到內容區 | 自然高度，手機兩欄排列 |
| Tab 缺少對應內容區 | 鍵盤及輔助工具難以定位 | Tabs.Content 與選取項正確關聯 |

| 手機部分操作目標偏小 | 不易點選 | 按鈕、圖示按鈕與 Tab 至少 44px 高 |

## 流程驗收

- 日常預約：切換日期／檢視 → 搜尋／篩選 → 建立預約 → 核對客戶 → 服務、人員及完整時長 → 選擇時段 → 建立 → 詳情／改期 → 報到與叫號 → 完成或取消。
- 回訪客戶：搜尋檔案 → 查看歷程 → 再次預約 → 核對完整身分資料，保留原本的身分保護。
- 院所設定：基本資訊／Logo → 人員 → 服務 → 服務對應／休假 → 排班與批次預覽。各頁籤支援鍵盤與上一頁。
- 平台管理：選擇院所 → 院所工作台／設定／訂閱 → 返回平台院所管理；帳號角色、院所綁定、申請審核與分類維護保留確認及錯誤重試。
- 訂閱：試用先確認、續約保留方案與付款歷史，失敗保留備註與輸入。
