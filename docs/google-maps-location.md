# 院所地圖位置：分享連結自動解析

新增、編輯院所共用 Google 地圖分享連結欄位，取代經緯度輸入框。在地點卡片選「分享 → 複製連結」後貼上，停止輸入約半秒即自動解析；亦可按「解析位置」重試。原本的地址、名稱不會被改寫。

## 操作

- 成功後顯示「已取得地圖位置，儲存院所後生效」，可點「在 Google 地圖確認」核對。
- 既有位置保留；不貼連結仍可編輯其他資料。按「移除位置」並儲存，才會清除座標。
- 解析中不能儲存；錯誤保留輸入與既有位置，可重試或清空新輸入後儲存。
- 更換連結或關閉彈窗會取消舊請求，遲到回應不覆蓋新位置。

## 解析範圍

支援 Google Maps 帶地點標記的完整網址、座標查詢，以及 `maps.app.goo.gl`、`goo.gl/maps` 分享短連結。短連結僅逐跳展開 Google 地圖網址；不需要新增付費 Google API 金鑰或後端資料表。

地點標記 `!3d/!4d` 優先。`@lat,lng`、`ll` 等地圖視窗中心不作為院所位置；路線與只有地點 ID、沒有可辨識座標的舊分享連結會顯示重複分享／改貼完整地點網址的提示，不猜測位置。真實公開短連結已驗證成功案例及只有地點 ID 的未辨識案例。

## 邊界與驗證

短連結解析 API 僅限同源且已通過後端驗證的後台帳號；限制請求大小、每帳號每執行個體的解析頻率、逾時與轉址跳數。每跳檢查 HTTPS、精確 Google 網域與地圖路徑，不轉送登入 token 或 Cookie 至 Google。

既有 API 保存 latitude／longitude；本次未變更資料庫或後端。單元測試涵蓋解析、錯誤與安全邊界；瀏覽器以虛構資料檢查新增、編輯、取消、移除、重試、舊回應競爭，以及手機／平板／桌機亮暗色。正式驗收不建立院所或修改真實資料。
